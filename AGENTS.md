# Agent guidance

- This is a standalone project. Never edit or import files from Toddler Keyboard.
- Keep the app vanilla HTML, CSS and classic JavaScript unless the user explicitly approves a new dependency.
- Offline-first is mandatory: no CDN, remote fonts, remote scripts, analytics, API calls, or cloud TTS during gameplay.
- Use only the supplied local MP3 files for speech. Keep all activity prompts as individual words and encouragement as short individual words wherever possible.
- Preserve Arabic RTL layout and large touch-friendly controls for ages 2–3.
- Do not add timers, lives, punitive feedback, score pressure, or harsh error sounds.
- Keep progress local to the device. Do not collect names or personal data.
- Increment the app version only for a completed, tested change, not every edit.
- Run `node --check` on changed JavaScript and perform PC/mobile smoke tests when feasible.

- Current activities: animals, colors, shapes, numbers and Arabic letters. Do not assume every alphabet letter is present; the current letter audio batch contains ألف، باء، جيم only.

- Use one persistent cat companion as the only speaking mascot. Keep it visible on both home and activity screens; do not add additional speaking animal characters unless the user explicitly asks.
- Reuse existing local greeting, target, praise and retry audio before asking for new recordings. Do not add speech that depends on online TTS.

- Current build version: v9.22. Keep the visible version label and metadata synchronized for future releases.
- Session length is 15 completed rounds. The optional end clip path is `assets/audio/instructions/game-ended.mp3`; do not assume it exists until supplied.

- v9.06 uses LocalAudio.play(audioId, onStart) and playCatAudio() to synchronize mouth/voice-bar animation with actual local audio playback. Preserve request-token cancellation behavior.

- v9.11 uses a frame-by-frame PNG paw-wave animation from `assets/cat/wave/`. Keep the idle pose still until matching blink/ear/tail artwork exists; do not fake those movements by moving the whole image.

- v9.12+ adds a separate mouth overlay (`#catMouthImage`, six 418×418 PNGs in `assets/cat/mouth/`) above the paw-wave image. The wave frames are independently drawn, so do not assume pixel-identical faces across them; the overlay has been verified to fully cover each wave frame's own mouth. From v9.14 the mouth follows per-clip loudness envelopes (`js/mouth-envelopes.js`, generated by `tools/build_mouth_envelopes.py` from the MP3s, read via the playing audio element's `currentTime`). Clips without an envelope fall back to the older random mouth. This is loudness-driven, not phoneme-accurate. **After adding or replacing any MP3, re-run the envelope tool.** Do not switch to live Web Audio analysis without testing `file://`, where `createMediaElementSource` can silence playback.

- v9.16 adds an idle blink: `#catBlinkImage` (`assets/cat/blink/eyes-closed.png`, built by `tools/build_blink_overlay.py`) is aligned with the idle pose (`wave/frame-01.png`) only, and `app.js` suppresses it whenever a wave is playing. Ears and tail still have no matching artwork, so keep them still. Blinking is skipped under `prefers-reduced-motion`.
- v9.16 caps a round at `MAX_CHOICES = 6` cards regardless of item count (the layout is built for 2-6). Do not remove the cap when adding items.
- To add letters: record MP3s per `docs/LETTER-RECORDING-CHECKLIST.md`, run `tools/add_letters.py`, then `tools/build_mouth_envelopes.py`.
