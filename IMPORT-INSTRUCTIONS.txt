Arabic Kitten Game v9.24 — GitHub import

The repository root is the only maintained project source. Do not use the old nested toddler3-publish snapshot.

1. Download the latest source from the repository's main branch (Code → Download ZIP), then extract it. Keep index.html, css/, js/, assets/, docs/, tools/, push-to-github.bat and toddler3-publish-to-github.ps1 together in the extracted project root.
2. Install Git for Windows and sign in to GitHub using Git Credential Manager or GitHub Desktop.
3. Double-click push-to-github.bat. The script clones https://github.com/suhaibshd7/toddler_3 to Documents\toddler_3 (or updates an existing fast-forwardable clone), then syncs the extracted project files into the repository root.
4. Before copying, the script reads the source and destination application-version values. It refuses to import an older or unversioned package, so a stale download cannot replace a newer app. No files are copied or committed when the source version is behind.
5. After a successful push, the repository root should contain index.html, css/, js/, assets/, docs/ and tools/. GitHub Pages should be set to: Deploy from a branch / main / /(root).

If Windows blocks scripts, open PowerShell in the extracted folder and run:
  Set-ExecutionPolicy -Scope Process Bypass
  .\toddler3-publish-to-github.ps1

The script prefers index.html in the same folder as itself. It accepts the old toddler3-publish subfolder only as a compatibility fallback, and still checks its version against the current repository before importing. The old nested snapshot has been removed from this repository; the root files are canonical.

The ZIP is only a transfer wrapper. The importer copies normal project files into the repository; it does not upload a ZIP into GitHub. Local MP3 recordings and WebP image assets remain part of the project.
